Монитор - безопасное и вычислительно эффективное уведомление о наступлении
события в параллельно выполняющихся потоках. Реализация на POSIX Threads
(C11, `pthread_mutex_t`, `pthread_cond_t`).

Требуется безопасно и эффективно реализовать монитор с двумя потоками:
потоком-поставщиком и потоком-потребителем.

Поток-поставщик должен с задержкой в одну секунду инициировать условное
событие, о чём должен выводить сообщение на экран. Поток-потребитель должен
это условное событие получать, о чём также должен сообщать на экране.

В итоге на экране должна появляться серия чередующихся сообщений об
отправлении события и его обработке. Сообщения не должны нарушать
очерёдность. Ожидание события должно происходить с минимальным потреблением
процессорного времени, т. е. быть практически равным нулю.

Подразумевается, что условное событие может содержать несериализуемые
данные (скажем, передаётся экземпляр класса по указателю)

В рамках лабораторной реализован монитор на POSIX Threads (C11, pthread_mutex_t, pthread_cond_t) и два потока, которые через него обмениваются событиями. Монитор объединяет разделяемое состояние, мьютекс для защиты доступа и условную переменную для ожидания уведомления
